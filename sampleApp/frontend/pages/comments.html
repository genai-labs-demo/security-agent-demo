What is Cross-Site Scripting (XSS)?

Cross-Site Scripting (XSS) is a security vulnerability that allows attackers to inject malicious scripts into web pages viewed by other users. When user input is displayed without proper sanitization or encoding, attackers can inject JavaScript code that executes in victims' browsers, potentially stealing cookies, session tokens, or performing actions on behalf of the user.

Types of XSS

  • Stored XSS: Malicious script is stored in the database and executed when displayed (demonstrated below)
  • Reflected XSS: Malicious script is reflected from the server in the response (demonstrated in search)
  • DOM-based XSS: Malicious script manipulates the DOM directly in the browser

Why It's Dangerous

XSS attacks can lead to:

  • Session hijacking (stealing authentication cookies)
  • Credential theft (capturing user input like passwords)
  • Defacement (modifying page content)
  • Phishing attacks (displaying fake login forms)
  • Malware distribution (redirecting to malicious sites)

How to Fix It

Always encode output and sanitize input: 

// ❌ VULNERABLE (no encoding)
res.send(`
${userInput}
`);

// ✅ SECURE (HTML encoding)
const escapeHtml = (text) => {
  return text
    .replace(/&/g, '&')
    .replace(//g, '>')
    .replace(/"/g, '"')
    .replace(/'/g, ''');
};
res.send(`
${escapeHtml(userInput)}
`);
